APK ni olish (kompyuterdan, bepul):
1. github.com da hisob oching va yangi repository yarating (Public).
2. Shu papkadagi BARCHA fayllarni (".github" papkasi bilan) repositoryga yuklang.
   Agar ".github" yuklanmasa: "Add file > Create new file" ga bosib, nomga
   .github/workflows/build.yml deb yozing va build.yml ichidagini qoʻying.
3. "Actions" bo'limiga kiring, "APK yigish" ishga tushguncha kuting (3-6 daqiqa).
4. Tugagach, ichiga kirib pastdagi "Shukurlar-daftari-apk" ni yuklab oling,
   zipdan app-debug.apk chiqadi. Uni telefonga yuboring va oʻrnating.
Ilova internetsiz ishlaydi (INTERNET ruxsati ham olinmagan).
